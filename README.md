# Ритм — веб-приложение для iPhone

## Что внутри
- Адаптивный интерфейс для iPhone и компьютера.
- Расписание, задачи, категории, заметки, отметка выполнения.
- Привычки с ежедневными отметками.
- Простая статистика за неделю.
- Локальное сохранение данных в браузере.
- Экспорт резервной копии в JSON.
- PWA-манифест, иконки и service worker для установки и базовой офлайн-работы.
- Запрос разрешения на уведомления и таймеры напоминаний, пока приложение открыто и браузер не выгрузил страницу.

## Важно про уведомления на iPhone
Для установки веб-приложения нужен HTTPS-сайт. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой» → добавьте приложение. В iOS/iPadOS 16.4+ веб-push доступен для веб-приложений, добавленных на экран «Домой», но для надёжных уведомлений при закрытом приложении нужен серверный push-сервис, регистрация push-подписки и сервер, который отправляет уведомления. В этой версии серверной части нет; локальные таймеры работают, пока приложение открыто и может выполнять JavaScript.

## Самый простой способ опубликовать бесплатно через Windows
1. Создайте аккаунт на GitHub.
2. Создайте публичный репозиторий, например `ritm-app`.
3. Загрузите в корень репозитория все файлы из этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
4. В репозитории откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)` и нажмите Save.
6. Дождитесь появления ссылки GitHub Pages. Откройте её в Safari на iPhone.
7. В Safari нажмите «Поделиться» → «На экран Домой» → включите при необходимости «Открывать как веб-приложение» → «Добавить».
8. Откройте «Ритм», зайдите в «Прогресс» и нажмите «Включить» для запроса разрешения на уведомления.

## Редактирование на Windows
Откройте `index.html` в Visual Studio Code или любом редакторе кода. Структура CSS, HTML и JavaScript находится в одном файле, чтобы стартовать было проще. После изменений загрузите файл в GitHub — сайт обновится после публикации.

## Ограничения текущего прототипа
- Данные хранятся только в этом браузере и не синхронизируются между устройствами.
- Нет аккаунтов, облачного хранения и серверных push-уведомлений.
- Уведомления по времени могут не сработать, если Safari выгрузил страницу или приложение закрыто.
- Пример расписания при первом запуске — демонстрационные данные; их можно удалить и заменить своими.
